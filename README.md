这是一个充满浪漫科技感的升级！为了将粒子轨道从圆圈改为完美的几何爱心（Heart Curve），我重写了核心的物理轨迹方程。
现在，当检测到手势时，粒子不会再沿圆周旋转，而是会以极高的速度在爱心数学曲线的外廓上交织流动。
方程与视觉微调：心形笛卡尔代数重构：代码中引入了高数经典心形线的极坐标转换为直角坐标方程 getHeartPos()。
粒子运动不再依赖简单的 $x^2 + y^2 = r^2$ 的圆，而是严格遵从 $16\sin^3(\theta)$ 运动。
